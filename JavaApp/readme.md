<h1>Приложение для изучения Java</h1>
<h3>Функционал по ролям</h3>

<h4>Пользователь:</h4>
<ul>
<li>Изучение теории</li>
<li>Прохождение тестов</li>
<li>Просмотр результатов тестов</li>
</ul>

<h4>Учитель:</h4>
<ul>
<li>Просмотр, добавление, изменение и удаление теории</li>
<li>Просмотр, добавление, изменение и удаление тестов</li>
</ul>

<h4>Администратор:</h4>
<ul>
<li>Просмотр статистики</li>
<li>Просмотр списка учителей</li>
<li>Создание и удаление учителей</li>
</ul>

<h3>Действия с профилем:</h3>
<ul>
<li>Регистрация (для пользователей)</li>
<li>Сброс пароля</li>
<li>Удаление (деактивация) аккаунта</li>
<li>Восстановление аккаунта</li>
<li>Просмотр профиля</li>
<li>Редактирование профиля</li>
<li>Изменение пароля</li>
</ul>

<h3>Дополнительный функционал:</h3>
<ul>
<li>Отправка сообщений по email</li>
<li>Шедулеры</li>
</ul>

<h3>Стек:</h3>
<ol>
<li>Spring Security</li>
<li>Flyway</li>
<li>Thymeleaf</li>
<li>PostgreSQL</li>
<li>SpringMVC</li>
<li>Spring Data JPA</li>
<li>Bean Validation</li>
<li>Docker</li>
</ol>
